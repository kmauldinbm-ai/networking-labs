# networking-labs

Hands-on networking labs documented while building practical IT and NOC troubleshooting skills.

## Incident troubleshooting

- [INC-013 — DHCP DNS option failure](dhcp-dns-incident-triage/) — isolate hostname-resolution failure from IP reachability; compare DHCP scopes and verify recovery.
- [INC-012 — DHCP relay incident triage](dhcp-relay-incident-triage/) — trace a branch DHCP failure through relay, routing, and lease verification.

Labs include Packet Tracer files, learner objectives, troubleshooting notes, and incident write-ups where available.
